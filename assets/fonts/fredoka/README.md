# Fredoka

Downloaded from the Google Fonts open-source repository:
https://github.com/google/fonts/tree/main/ofl/fredoka

`Fredoka-Variable.ttf` is the original file, distributed with the included `OFL.txt` license. The static files cover Light (300), Regular (400), Medium (500), SemiBold (600), and Bold (700), all at normal width 100. They were generated using FontTools and are bundled for reliable PDF embedding without extra generation dependencies.

Set `FONT_NAME` in the project's `game_config.py` to `"fredoka-light"`, `"fredoka-regular"`, `"fredoka-medium"`, `"fredoka-semibold"`, or `"fredoka-bold"`. The existing `"fredoka"` option remains an alias for Bold. Set it to `"manrope"` to restore the preceding design.
